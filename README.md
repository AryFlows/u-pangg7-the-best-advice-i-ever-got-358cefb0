One sentence on the best advice ever received, for the make.fun
competition "The Best Advice I Ever Got".

> Grandma said never trust a man who says 'trust me' — forty years later, every single one of them has proved her right.

## Run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Python standard library only.

Entry: 118 characters, one sentence, inside the competition's 1–200 gate.
